# 图集捕手 · 电商图片下载插件

图集捕手是一款面向电商运营场景的图片整理工具，支持商品主图、详情图和 SKU 图的识别、筛选与批量下载。

## 在线预览

https://zhaohhee.github.io/ecommerce-image-downloader/

## 核心功能

- 一键识别商品页面中的图片
- 主图、详情图、SKU 图分类展示
- 批量勾选与下载
- 本地处理，减少数据外传
- 响应式官网页面

## 技术栈

- HTML5
- CSS3
- JavaScript
- GitHub Pages
